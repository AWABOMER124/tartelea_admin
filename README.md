# Tartelea Admin Hub

واجهة إدارة عربية مبنية بـ Next.js وتعمل الآن فوق `Backend API` الموحّد بدل أي اتصال مباشر من الواجهة إلى قاعدة البيانات.

## التشغيل

1. جهّز ملف البيئة:

```bash
cp .env.example .env.local
```

2. عدّل `NEXT_PUBLIC_API_BASE_URL` إذا كان الـ backend يعمل على عنوان مختلف، وحدد نطاق الإدارة في `ADMIN_ALLOWED_HOSTS`.

3. شغّل التطبيق:

```bash
npm install
npm run dev
```

4. افتح `http://localhost:3000` ثم استخدم زر "تسجيل الدخول" لربط اللوحة بحساب `admin` أو `moderator`.

## ما الذي تديره اللوحة؟

- الإحصاءات التنفيذية
- المستخدمون والأدوار
- المحتوى
- المنشورات: العنوان والنص الكامل
- دورات المدربين: العنوان والوصف والتصنيف والنوع والمستوى والسعر والوسائط والروابط
- الورش: العنوان والوصف والتصنيف والموعد والمدة والسعر والسعة والصورة
- الغرف: العنوان والوصف والتصنيف والموعد والمدة والسعر والسعة ونوع الوصول والصورة
- المحتوى المثبت
- الإشعارات
- سجل التدقيق

## ملاحظات

- تعتمد اللوحة على JWT الصادر من الـ backend.
- عنوان الـ API الافتراضي هو `http://localhost:3001/api/v1`.
- إذا لم تكن الجداول الجديدة مطبقة بعد، نفّذ `backend/schema.sql` أولًا.

## النشر على نطاق إدارة مستقل

اضبط متغيرات النشر التالية قبل بناء الصورة:

```env
NEXT_PUBLIC_API_BASE_URL=https://api.tartelea.com/api/v1
ADMIN_ALLOWED_HOSTS=admin.tartelea.com
```

- اربط خدمة هذه اللوحة بنطاق الإدارة فقط، مثل `admin.tartelea.com`، ولا تمررها عبر نطاق الموقع العام.
- أضف `https://admin.tartelea.com` إلى `ALLOWED_ORIGINS` في خدمة الـ backend.
- يتم تضمين عنوان الـ API وقت بناء تطبيق Next.js، لذلك يجب تمريره كـ build argument عند استخدام Docker.
- أي Host غير موجود في `ADMIN_ALLOWED_HOSTS` يحصل على 404، والصفحات تحمل توجيهات `noindex` لمحركات البحث.
- هذا العزل لا يحل محل الحماية الفعلية: جميع عمليات الكتابة ما زالت تتحقق من JWT ودور `admin` في الـ backend.
